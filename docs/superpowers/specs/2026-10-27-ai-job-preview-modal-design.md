# AI job preview modal

Approved in chat: clicking an AI job or completion notification opens a modal without navigation. Display loading, status, error, and scrollable results. Markdown note results have an explicit apply action; unsaved workspace changes block application and the backend source hash remains authoritative. Imports and generated questions show question previews with a link to their existing workflow. Support close button, Escape, focus containment/restoration, and old retained results. Match the current dark workspace.
